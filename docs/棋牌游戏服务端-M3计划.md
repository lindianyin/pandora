## 1. 范围

### 包含

- `WalletService` + `MemoryStore` 金/钻账本（`ledger` 幂等键）
- 结算经 Wallet：`settle:{round_id}:{uid}`
- HTTP：`GET /api/v1/player/profile`、`POST /api/v1/wallet/exchange`
- `PayService`：档位、支付宝下单（占位 orderStr）、notify、sandbox_complete
- 断线托管 + `S2C_DdzReconnect`（2008）重连快照
- game-web：`/wallet`、自动重连、托管态展示

### 约定

- 默认 `store.backend=memory`；选 `mysql` 时本里程碑告警并回退 memory（DDL 见 `server/sql/schema.sql`）
- Redis 不作为 M3 阻断项
- 支付宝：`alipay.sandbox=true` 时可用网页「模拟到账」演示，无需真机 APP

## 3. 验收

1. 结算 / 兑换 / 支付幂等键不双扣（见 `m3_smoke.mjs`）
2. 沙箱：拉档位 → 下单 → sandbox_complete → 钻石增加
3. 对局断线进入托管；重连后己方手牌恢复，不推他人手牌
4. game-web `/wallet` 可用；三开对局回归
5. 无 MySQL 时 memory 核心链路可跑

```powershell
# 服务端已启动后
node server\scripts\m3_smoke.mjs
```
