# 跑胡子规则文档

| 项 | 内容 |
|----|------|
| 文档用途 | 玩法说明与后续服务端实现参考（非地方协会官方标准） |
| 适用范围 | **3 人**字牌跑胡子 |
| 默认配置档 | **湖南经典（邵阳系）**：80 张、15 息起胡、只胡摸牌/示众牌、不放炮 |
| 版本 | V1.0 |
| 更新日期 | 2026-10-08 |

> **说明**：跑胡子（又称字牌、剥皮胡）在湖南、四川、贵州等地差异很大。本文以可配置方式描述完整规则，**默认实现采用湖南三人经典玩法**；其它变体见文末「可选配置」。

---

## 1. 概览

| 项 | 规则 |
|----|------|
| 人数 | **3 人**（庄 ×1 + 闲 ×2） |
| 牌副 | **80 张**字牌（小写一～十、大写壹～拾，各 4 张） |
| 行牌 | 可吃、碰、偎、跑、提；**碰优先于吃**；偎 / 跑 / 提多为强制 |
| 核心特色 | 胡息制、门子制、红黑字名堂、摸牌胡（默认不放炮） |
| 胡牌门槛 | 凑满 **7 个门子**，且胡息 **≥ 15**（三提五坎等天胡例外） |

一句话：跑胡子 = **字牌 + 偎跑提 + 胡息囤数 + 红乌名堂**。

## 2. 牌组与颜色

### 2.1 牌张

| 类型 | 内容 | 张数 |
|------|------|------|
| 小写（小字） | 一、二、三、四、五、六、七、八、九、十 | 10 × 4 = 40 |
| 大写（大字） | 壹、贰、叁、肆、伍、陆、柒、捌、玖、拾 | 10 × 4 = 40 |
| **合计** | | **80** |

> 「陆」与「六」同属大字 / 小字体系中的「6」；书写可用「陆」或「陸」。

### 2.2 红字与黑字

| 颜色 | 牌面 |
|------|------|
| **红字** | 小字：二、七、十；大字：贰、柒、拾（共 6 种 × 4 = **24 张**） |
| **黑字** | 其余全部（**56 张**） |

红字用于红胡 / 点胡 / 乌胡等名堂统计。

### 2.3 牌面标识建议（实现用）

可对每种牌分配稳定 ID（示例）：

| 范围 | 含义 |
|------|------|
| `0..9` | 小字一～十 |
| `10..19` | 大字壹～拾 |
| 每种 4 张 | 实现层用张数计数即可，不必区分同名四张 |

## 3. 定庄、发牌与座位

### 3.1 定庄 / 连庄

| 情况 | 规则 |
|------|------|
| 首局 | 随机定庄（或骰点最大者） |
| 有人胡牌 | **胡家坐庄**（下局为庄） |
| 流局（荒庄） | 庄家继续坐庄 |

座位按逆时针；摸牌、出牌、吃碰响应也按逆时针（从上家起）。

### 3.2 发牌

| 角色 | 张数 |
|------|------|
| 庄家 | **21**（20 + 1 张亮张 / 庄家起手多摸一张） |
| 闲家 | 各 **20** |
| 牌墩（底牌） | 剩余 **19** |

常见流程：

1. 洗牌后砌墩。
2. 按座位发满闲家 20、庄家 20，再由庄家多摸 1 张（或直接发 21）。
3. 庄家先打出第一张（部分玩法：亮张须先处理天胡 / 提跑等，再出牌）。

### 3.3 重要行牌原则（字牌特有）

1. **摸进的牌默认不入手**  
   除庄家起手那张外，玩家从牌墩摸起的牌一般**不得放进暗手**。若不能吃碰偎跑提胡，则将该牌**示众（亮出）**后当作「弃牌 / 示众牌」，供下家吃碰等（具体能否被胡见 §7）。
2. **吃碰偎跑提之后通常要出牌**  
   第一次跑 / 提后要出一张；**第二次及以后的跑 / 提可不再出牌**（「跑提一次后免出」）。
3. **操作优先级（默认）**  
   `提 > 胡 > 跑 > 碰 > 吃`（同优先级时：自摸优先；多人胡同一示众牌时下家优先）。

## 4. 牌组结构（门子）

胡牌时，桌上已亮的组合 + 手牌，合计须能拆成 **7 个门子**（7 组）。常见门子类型如下。

### 4.1 同牌类

| 名称 | 组成 | 形成方式 | 亮暗（默认） |
|------|------|----------|--------------|
| **坎** | 起手三张相同 | 发牌后手中已有三张同名 | 暗（不亮给他人） |
| **碰** | 手中两张 + 他人打出 / 示众一张 | 主动碰 | 三张全明 |
| **偎** | 手中两张 + **自己摸进**一张 | 强制偎（默认） | 三张暗，或己方可见、他人暗 |
| **臭偎** | 本可碰却先过、之后又偎成三张 | 部分地区单独命名 | 同偎 |
| **跑** | 已有坎 / 碰 / 偎，再得到第四张（他人打出 / 示众 / 他人摸出示众） | **强制跑** | 四张全明 |
| **提（拢）** | 已有坎 / 偎，**自己摸进**第四张；或起手四张相同 | **强制提** | 三暗一明（亮一张） |

### 4.2 顺类与绞

| 名称 | 组成 | 胡息 |
|------|------|------|
| **一句话（顺子）** | 同大小写体系内连续三张，如 `四五六`、`柒捌玖` | 0 |
| **一二三 / 壹贰叁** | 特殊顺：小写一二三 / 大写壹贰叁 | 见 §5 |
| **二七十 / 贰柒拾** | 特殊顺：小写二七十 / 大写贰柒拾 | 见 §5 |
| **绞（绞牌）** | 两张同名小字 + 一张同数大字，或两张同名大字 + 一张同数小字，组成「假刻」类门子 | 0 |

> 「一句话」只能同体系（小字只能跟小字、大字只能跟大字）连顺；不能跨大小写拼 `二叁四`。

### 4.3 将 / 对子

- 默认胡型以 **7 门子** 计；若出现跑或提，牌张总数会变化，允许以 **对子（将）** 补足结构（有跑 / 提时常见）。
- 具体「7 门子」计数方式以实现为准：桌上每一碰 / 偎 / 坎 / 跑 / 提 / 一句话 / 绞各算 1 门；手牌剩余部分继续拆门，凑满 7。

## 5. 胡息

胡息是能否胡牌与计囤的基础。下表为**默认湖南经典**取值。

| 门子 | 小字胡息 | 大字胡息 |
|------|----------|----------|
| 碰 | 1 | 3 |
| 坎 / 偎 / 臭偎 | 3 | 6 |
| 跑 | 6 | 9 |
| 提 | 9 | 12 |
| 一二三 | 3 | — |
| 壹贰叁 | — | 6 |
| 二七十 | 3 | — |
| 贰柒拾 | — | 6 |
| 普通一句话 | 0 | 0 |
| 绞 | 0 | 0 |

**起胡线**：胡息合计 **≥ 15**（未达标不可胡，三提五坎等例外除外）。

## 6. 吃、碰、偎、跑、提细则

### 6.1 吃

- 仅**下家**可吃上家打出或示众的牌（与麻将类似）。
- 用手中两张与之组成一句话 / 一二三 / 二七十 / 绞等合法门子。
- 吃后必须打出一张。
- **过吃**：对某张示众牌选择过后，本圈通常不得再吃同一张（可配置）。

### 6.2 碰

- 手中有两张同名，他人打出或示众第三张时可碰（非下家也可）。
- **碰优先于吃**。
- 碰后必须出牌。

### 6.3 偎（强制）

- 手中有两张同名，**自己从墩上摸到**第三张 → 必须偎。
- 偎牌不入手，直接落入门前（暗放）。
- 偎后须出一张（除非本回合另有跑 / 提免出规则触发）。

### 6.4 跑（强制）

出现下列之一即跑：

1. 门前或手中已有坎 / 碰 / 偎，他人打出或示众第四张；
2. 已碰过该牌，之后自己或他人从墩上摸到第四张并示众。

跑牌四张全明。第一次跑后要出牌；之后再跑可不打。

### 6.5 提（强制）

1. 起手即四张相同 → 提；
2. 已有坎 / 偎，自己摸进第四张 → 提。

提为三暗一明。第一次提后要出牌；之后再提可不打。

### 6.6 禁止与限制（默认）

- 不得用偎 / 提的牌被他人胡（他人不能点「偎牌 / 提牌」）。
- **不能胡别人打出的牌**（无放炮）；可胡：自己摸进、他人摸后示众且规则允许的牌。
- 不能胡任何人的提牌；偎牌是否可被自己继续组成胡型按门子规则计，但他人不可「点偎胡」。

## 7. 胡牌

### 7.1 基本条件

同时满足：

1. 牌型可拆成合法 **7 门子**（见 §4）；
2. 胡息 **≥ 15**；
3. 所胡之牌来自 **牌墩摸进或合法示众**，而非他人主动打出（默认无放炮）。

### 7.2 天胡 / 特殊（可选开关）

| 名称 | 条件 | 说明 |
|------|------|------|
| **三提五坎** | 起手 3 个提或 5 个坎 | 可直接胡，门子 / 息数要求放宽或按房间配置 |
| **天胡** | 庄家亮张即可胡 | 息数 / 囤数计算可单独配置 |

### 7.3 多人同时可胡

| 情形 | 优先级 |
|------|--------|
| 自己摸进的牌 | **摸牌者优先** |
| 他人示众牌两家可胡 | **下家优先** |
| 与庄家亮张相关 | 按房间约定；默认「不需亮张的天胡」优先于「依赖亮张的天胡」 |

## 8. 名堂（番）

名堂在囤数之上乘算。下表为**推荐默认**（各地番数差异大，实现务必可配）。

| 名堂 | 条件 | 默认番 |
|------|------|--------|
| 平胡 | 无名堂 | ×1 |
| 自摸 | 胡的是自己从墩上摸进的牌 | ×2（可并入囤 +1，见 §9） |
| 点胡 | 红字 **恰好 1 张** | ×3 或 ×4（可配） |
| 小红胡 / 红胡 | 红字 **10～12** 张 | ×2 |
| 大红胡 | 红字 **≥ 13** 张 | ×4（可再「每多 1 红 +1 番」） |
| 乌胡（黑胡） | 红字 **0** 张 | ×5 |
| 十八小 | 小字 **≥ 18** 张 | ×6 |
| 对对胡 | 7 门子皆为碰 / 偎 / 坎 / 跑 / 提 / 将，无顺无绞 | ×5 或 ×6 |

> 多个名堂默认**番数累加或相乘**由配置决定；推荐首发采用 **相乘** 或「主名堂取最高 + 自摸另计」，并在房间模板写死一种。

## 9. 计囤与结算

### 9.1 囤数（默认）

以 15 息为 1 囤，每多 3 息 +1 囤：

```text
囤数 = floor((胡息 - 15) / 3) + 1
```

等价常见写法：`floor((胡息 - 12) / 3)`（在胡息 ≥ 15 时与上式一致）。

| 胡息 | 囤数 |
|------|------|
| 15～17 | 1 |
| 18～20 | 2 |
| 21～23 | 3 |
| … | … |

- **自摸**：可在囤数上 **+1 囤**（与名堂×2 二选一或并存，须配置唯一算法）。
- **天胡**：可用单独公式，例如 `(胡息 × 2 - 12) / 3` 再处理自摸。

### 9.2 得分（默认三人）

设：

- `x` = 囤数  
- `f` = 名堂总番（平胡为 1）  
- `d` = 房间底分  

```text
赢家得分 = x × f × 2 × d      // 两家各付一份，合计两份
每家闲家失分 = x × f × d
```

庄闲是否另有倍数：默认**无额外庄闲倍**；可配置「庄家输赢 ×2」。

### 9.3 流局

牌墩摸完仍无人胡 → 流局：无胡息结算（或计「查叫」：未达听牌者赔付，可配关闭）。默认：**无账变，庄家连庄**。

## 10. 一局流程（摘要）

```text
定庄 → 发牌（庄21 / 闲20 / 墩19）
  → 处理起手提 / 天胡
  → 庄家打出第一张
循环:
  下家可吃；任意家可碰 / 跑；强制偎 / 提在摸牌时处理
  → 有动作则执行并（按规则）出牌
  → 否则下一玩家摸墩：能胡则胡；能提 / 偎 / 跑则强制；
     否则示众，供他人碰跑吃，再继续
  → 直至有人胡或墩尽流局
结算囤数 × 名堂 × 底分
```

## 14. FAQ

**Q：能不能胡别人打的牌？**  
A：默认不能。只胡自己摸的或规则允许的示众牌。

**Q：偎和碰有什么区别？**  
A：第三张是自己摸进的为偎（多强制、多暗）；第三张是别人打出 / 示众的为碰（明、可选择）。

**Q：为什么有的牌摸了不能拿手上？**  
A：字牌传统：摸牌先判断能否组成偎跑提胡；不能则示众，避免「摸到手再随意拆打」破坏信息结构。

**Q：15 息但门子不够 7 个能胡吗？**  
A：不能。息数与门子两个条件都要满足（天胡类例外除外）。

**Q：红胡和点胡冲突怎么办？**  
A：点胡要求红字恰好 1；红胡要求红字 ≥10。二者不会同时成立。乌胡与红胡互斥。

## 15. 参考与差异声明

线上平台（如各「湖南跑胡子」房间）在名堂番数、自摸加囤 / 加番、红胡累进、臭偎命名上并不统一。本文默认档对齐「80 张、三人、15 息、偎跑提强制、不放炮、囤数随息递增」这一主流骨架；上线前应以产品选定的房间模板为准，并同步修改本文件与 SPEC。

改默认规则时：先改本文 → 再改 `docs/跑胡子-SPEC.md` → 再改协议与代码。
