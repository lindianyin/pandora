---

## 1. 范围

### 包含

- SessionHub + 消息分发（大厅/匹配/房间/斗地主）
- 大厅场次、快速匹配（3 人成桌）、Ready、RoomState
- `DdzClassicSimple`：发牌、叫分、出牌校验、炸弹翻倍、春天、结算
- 内存钱包 `AdjustGold`（幂等键 `settle:{round_id}:{uid}`）
- game-web：`/lobby` 式大厅 UI + 最小牌桌
- 牌型单测 `ddz_cards_test`

### 不做（M3+）

- MySQL/Redis、支付宝、完整断线重连快照、Admin CRUD、活动

---

## 2. 验收

1. GetLobby / QuickMatch / 成桌或 30s 超时  
2. 三人 Ready 后叫分/出牌；非法牌型返回 Error  
3. `S2C_DdzSettle` 与金币变化；重复结算幂等  
4. 三开 game-web 打完一局  
5. `ddz_cards_test` 通过；M1 health/登录/心跳仍可用
