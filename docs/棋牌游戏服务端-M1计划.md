## 1. 范围

### 包含

- CMake / MSVC 工程骨架：`pandora-server` 可编译运行
- 配置：`server/conf/server.json`（HTTP/WS 端口、业务常量）
- **帧协议**：`uint32 LE 长度头 | uint32 LE msg_id | Protobuf 消息体`（手写 `proto_wire` / game-web `frame.ts`）
- HTTP：`GET /health`、游客登录 `POST /api/v1/auth/login`（Bearer Token）
- WSS：`C2S_Auth` / `S2C_AuthResult`、`C2S_Heartbeat` / `S2C_HeartbeatAck`、`S2C_Kick` / `S2C_Error`
- 进程内 `MemoryStore`：游客账号、会话 Token（后续里程碑再落 MySQL/Redis）
- Proto 约定落盘：`proto/common.proto` 等（本里程碑以手写编解码为主，不强制 codegen）

### 不做（M2+）

- 大厅 / 匹配 / 斗地主对局
- 钱包 / 支付 / 断线重连
- MySQL / Redis / Admin / 活动
- 生产级 TLS 证书（本地可用明文或自签；强制 TLS 留给部署阶段）

## 3. 验收

```powershell
cd server
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
cd build\Release
.\pandora-server.exe

# 另开终端
node server\scripts\ws_smoke.mjs
```

1. `GET /health` 返回 `status=ok`（及后续扩展字段）
2. 游客登录拿到 `access_token` / `uid` / 初始金币
3. WSS 连接后 Auth 成功；心跳往返正常
4. 非法 Token 鉴权失败；踢线可收到 Kick（若触发）
5. 帧长度头 / msg_id 为 **u32 little-endian**，与 SPEC 一致
