# 杭州麻将规则文档

| 项 | 内容 |
|----|------|
| 文档用途 | 玩法说明与服务端实现参考（非法律/地方协会官方标准） |
| 适用范围 | 4 人杭州麻将 · 无花牌 |
| 默认配置档 | **线上主流：白板固定财神**（见 §2.1） |
| 版本 | V1.1 |
| 更新日期 | 2026-09-30 |

> **说明**：杭州麻将存在「白板固定财神」与「掷骰翻财神」等线下/平台差异。本文以可配置方式描述完整规则，**默认实现采用白板固定财神**；其它变体见文末「可选配置」。

---

## 1. 概览

| 项 | 规则 |
|----|------|
| 人数 | 4 人（庄 ×1 + 闲 ×3） |
| 牌副 | 136 张，无梅兰竹菊 / 春夏秋冬花牌 |
| 行牌 | 可吃、碰、明杠、暗杠、补杠；**碰/杠优先于吃** |
| 核心特色 | 财神（百搭）、爆头、财飘、杠上开花（杠串）、三摊承包 |
| 胡牌默认 | **平庄只可自摸**；**三连庄（三牢）起庄闲之间可点炮**（闲闲之间仍不可点炮，可配置） |

一句话：杭州麻将 = **财神百搭 + 爆头/财飘 + 杠串 + 三摊承包**。

## 2. 牌组与定庄

### 2.1 牌张

| 类型 | 内容 | 张数 |
|------|------|------|
| 序数牌 | 万、条、筒各 1～9 | 3 × 36 = 108 |
| 风牌 | 东南西北 | 16 |
| 箭牌 | 中、发、白 | 12 |
| **合计** | | **136** |

### 2.2 定庄 / 连庄

| 情况 | 规则 |
|------|------|
| 首局 | 随机定庄（或骰子最大者） |
| 有人胡牌 | **抢庄**：胡牌者下局坐庄（连庄计数见 §2.3） |
| 流局（荒庄） | 庄家继续坐庄，并计入连庄 |

座位按逆时针；摸牌、出牌、吃碰杠响应也按逆时针（从上家起）。

### 2.3 连庄档位（庄闲倍数）

| 档位名 | 含义（常见说法） | 庄闲倍数 N |
|--------|------------------|------------|
| 平庄 / 一连庄 | 新庄或首次坐庄 | **×2** |
| 二连庄 | 连庄 2 次 | **×4** |
| 三连庄及以上（三牢） | 连庄 ≥3；再连仍按本档 | **×8（封顶）** |

> 部分线上房间提供「**开局即三牢**」：全员按 N=8 结算，忽略连庄计数（可配置开关）。

## 3. 财神（百搭）

### 3.1 默认：白板固定财神

- 每局 **白板 4 张** 全部为财神（赖子 / 百搭）。
- 财神可代替任意牌组成对子、刻子、顺子（组成七对时同样可代替）。
- **禁止**：用财神去「凑」吃 / 碰 / 杠别人打出的牌；别人打出的财神 **不可被吃碰杠胡**。
- 财神可以主动打出；打出后视为打出白板，触发 **财飘**（见 §6），且该张不可被吃碰杠。

### 3.2 变体：翻财神（可选）

1. 发牌后按骰子定位翻出一张指示牌，**该牌面为财神**（牌池中同名牌仅剩 3 张为财神）。
2. **白板替代**被翻出的那张牌面（白板当普通牌用）。
3. 其余百搭限制与 §3.1 相同。

实现时用配置 `caishen_mode = fixed_bai | flip` 切换。

## 4. 开局与行牌

### 4.1 发牌

- 庄家 **14** 张，三家闲家各 **13** 张。
- 庄家先出牌（或先补花后再出，本玩法无花）。

### 4.2 回合流程

```text
摸牌 →（可暗杠/补杠）→ 出牌
         ↑                    ↓
         └── 他家响应：胡 > 杠 > 碰 > 吃（仅下家可吃上家）
```

| 操作 | 规则 |
|------|------|
| 吃 | 仅可吃 **上家** 打出的序数牌，与手牌两张组成同花色顺子 |
| 碰 | 手牌有两张相同，可碰任意家打出；**不可碰财神** |
| 明杠（直杠） | 手牌三张相同，别人打出第四张；**不可杠财神** |
| 暗杠 | 手牌四张相同；打出后可补牌 |
| 补杠（续杠） | 已碰的牌再摸到第四张；可被抢杠（见 §5.3） |
| 优先级 | **胡 > 杠 > 碰 > 吃**；多人同时胡时，从出牌者下家起逆时针，先者优先（一炮一响，默认） |

### 4.3 财飘期间的限制（重要）

当某玩家打出财神进入「飘」状态时（§6）：

- **其它三家本圈只能摸打**：不可吃、碰、明杠、点炮胡（暗杠是否允许由配置决定，默认 **仅允许暗杠** 或不允许，建议默认不允许出飘期间的任何副露/胡）。
- 飘家摸进下一张牌后，若再打出非财神，则飘状态解除；若再打出财神则连飘升级。

## 5. 胡牌

### 5.1 基本牌型（平胡）

须满足经典「**一对将 + 四组面子**」（面子为顺子或刻子/杠）：

| 形态示意 | 说明 |
|----------|------|
| 11 + 123×4 | 一对将 + 四顺 |
| 11 + 顺/刻组合 | 顺刻混搭共四组 |
| 11 + 111×4 | 一对将 + 四刻（大对子类，仍算可胡牌型） |

### 5.2 特殊牌型：七对

- **七对**：手牌为 7 个对子（可用财神凑对）。
- **豪华七对**：七对中含 1 个「四张相同」（计为一个对子的强化，见 §7 倍数表）。
- **双/三豪华**：含 2 / 3 个四张相同。
- **清七对**：七对中 **无财神**。

### 5.3 自摸与点炮（三牢点炮）

| 连庄档位 | 庄闲点炮 | 闲闲点炮 | 抢杠胡 |
|----------|----------|----------|--------|
| 平庄 / 二连庄 | **否**（只能自摸） | 否 | 可配置，默认允许且按杠开类计 |
| 三连庄及以上 | **允许庄↔闲点炮** | **默认否** | 允许 |

补充：

- **一炮一响**（默认）：多家可胡同一张点炮牌时，仅一人胡成。
- **漏胡**（可选）：听某张牌时，若放弃下家打出的该张，则本圈对该张漏胡；其它听口不受影响。默认建议开启。
- **自摸时机**：只在摸进一张之后（含庄家起手 14 张、杠后补牌）。吃、碰之后即使剩余手牌已经是和牌形，也须先打出一张，不能宣告自摸。

### 5.4 流局

牌墙摸完仍无人胡 → 流局：不计算胡牌分；连庄计数 +1；庄家续庄。

## 6. 爆头与财飘

这是杭州麻将与其它玩法差异最大的部分。

### 6.1 爆头

- 将牌由 **一张财神 + 一张真牌** 组成（财神当将的一半）。
- 玩家已听牌，且 **下一张任意摸进都可与该财神成将而胡**（俗称「财神单吊 / 爆头听」）。
- 此时自摸胡牌称为 **爆头**，胡牌倍数 ×2（见 §7）。

> 直观理解：手里用财神吊着某一个将，摸什么都能「配上」而成和。

### 6.2 财飘（飘财神）

1. 爆头状态下，若手中还有多余财神，可 **打出一张财神** → 进入 **财飘**。
2. 飘出后仍保持「下一张摸进即可胡」的状态；若摸进成胡，则按财飘倍数计。
3. 若摸进后未能胡而打出非财神，则飘失败，回到普通行牌。
4. 连续打出财神可升级：

| 名称 | 条件 | 倍数（相对平胡） |
|------|------|------------------|
| 爆头 | 爆头听后自摸 | ×2 |
| 财飘 | 爆头后成功飘 1 次再胡 | ×4 |
| 双财飘 | 连续飘 2 次再胡 | ×8 |
| 三财飘 | 连续飘 3 次再胡 | ×16 |

### 6.3 杠开（杠上开花）与杠串

| 名称 | 条件 | 倍数 |
|------|------|------|
| 杠开 | 杠后补牌直接胡 | ×2 |
| 二连杠 | 连续第二次杠后补牌胡 | ×4 |
| 三连杠 | 连续第三次杠后补牌胡 | ×8 |
| 四连杠 | 连续第四次杠后补牌胡 | ×16 |

**组合**（倍数相乘，常见）：

| 名称 | 含义 | 倍数示例 |
|------|------|----------|
| 杠爆 | 杠开且爆头 | 2×2=4 |
| 杠飘 | 先杠开再财飘成胡 | 2×4=8 |
| 飘杠 | 先财飘再杠开成胡 | 4×2=8 |

## 8. 结算

### 8.1 公式

```text
胡牌分额 stake = 底分 × 胡牌倍数 M

庄闲倍数 N：见 §2.3（2 / 4 / 8）

自摸：
  - 庄家胡：每个闲家支付 stake × N；庄家共收 3 × stake × N
  - 闲家胡：庄家支付 stake × N；另外两闲各支付 stake × 1

点炮（仅三牢允许庄闲点炮时）：
  - 默认点炮者一人支付应付总额（或按「点炮者付 N 份、其余不付」的本地细则配置）
  - 建议默认：**点炮者承担本应向胡家支付的全部分成**（三人份或庄闲份，按上式汇总）
```

金币结算示例（闲家自摸，平庄 N=2，M=4，底分 100）：

```text
stake = 100 × 4 = 400
庄家付 400 × 2 = 800
另两闲各付 400
胡家共得 800 + 400 + 400 = 1600
```

### 8.2 三摊承包（包牌）

以玩家 A、B 为例：

1. **A 吃（及部分规则含碰）B 的牌累计满 3 次**（三摊），记 A 被 B「三摊」。
2. 若之后 **B 胡牌**：由 **A 一人承包** B 本局胡牌应收的全部分成（另外两家不付）。
3. 若之后 **A 胡牌**：由 **B 承包** A 应收全部分成（细则可再 × 庄闲关系）。
4. 吃摊计数：**只统计吃同一家**；换一家吃不累加到同一计数器。
5. 是否「碰也算摊」：默认 **吃算摊、碰也算摊**（可配置 `peng_counts_tan=true`）。

承包与庄闲倍数同时生效：承包方按「应付总额」一次性支付。

### 8.3 杠分（即时分，可选）

部分场次杠牌即时结算，与胡牌分独立：

| 杠类型 | 常见付分 |
|--------|----------|
| 明杠 | 放杠者付 3 × 底分 |
| 暗杠 | 三家各付 2 × 底分 |
| 补杠 | 三家各付 1 × 底分 |

也可做成「杠分并入终局倍数、不即时结算」。房间模板二选一。

## 9. 状态机（服务端参考）

```text
WaitReady → Deal → (FlipCaishen?) → Play → Settle → WaitReady
                              ↘ DeadWallEmpty → LiuJu → WaitReady
```

| 状态 | 行为 |
|------|------|
| WaitReady | 满 4 人且准备 → Deal |
| Deal | 洗牌、定庄、发牌；`fixed_bai` 则白板为财神；`flip` 则掷骰翻牌 |
| Play | 摸打与吃碰杠胡；维护连飘计数、三摊计数、听牌/爆头标记 |
| Settle | 算 M、N、承包、写账变、推送结算 |
| LiuJu | 流局：连庄 +1，无胡牌分 |

权威校验全部在服务端；客户端仅展示。

## 12. FAQ

**Q：白板能不能碰？**  
A：固定白板财神模式下，白板是财神，**不能碰、不能杠**；只能留手百搭或打出飘。

**Q：平庄能点炮吗？**  
A：默认不能，只能自摸。三连庄（三牢）起，庄闲之间可以点炮。

**Q：三摊承包吃几次算？**  
A：对 **同一家** 吃满 3 次（默认碰也算）。换一家重新计数。

**Q：财飘失败怎么办？**  
A：飘后摸进不能胡且打出非财神，则飘状态取消，倍数不加财飘，恢复正常吃碰胡。

**Q：和「翻财神」老规矩冲突怎么办？**  
A：用房间配置切换；同一场次模板内规则必须唯一，并在开局协议里下发给客户端展示。
