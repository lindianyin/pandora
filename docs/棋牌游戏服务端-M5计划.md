## 1. 范围

### 包含

- 首发三类活动：`sign`（每日签到）、`task`（完成 N 局）、`gift`（限时限量礼包）；**不含冲榜**
- `ActivityService`：定义热更、进度、领奖幂等、礼包库存；进度/领取/库存落 **MySQL + Redis**（无进程内 memory 回退）；异常 try/catch 隔离，不阻断 settle/match
- 结算 / 登录挂钩：`OnGameSettled` / `OnLogin`；变化推 `S2C_ActivityUpdate`（msg_id **3001**）
- 玩家 HTTP：`GET /api/v1/activity/list`、`GET .../progress`、`POST .../claim`
- Admin：`GET/POST/PUT/DELETE /admin/v1/activities`；审计；`POST .../simulate_settle`（冒烟模拟结算推进任务）
- game-web `/activity`；admin-web 活动 CRUD

### 不做（M6+）

- 冲榜 / 排行榜活动
- 真实支付宝验签
- 报表导出

## 2. rules_json 约定（种子）

| type | 示例 rules |
|------|------------|
| sign | `{"reward_key":"daily","reward":{"currency":1,"amount":500},"timezone":"Asia/Shanghai"}` |
| task | `{"target_games":3,"reward_key":"games_3","reward":{"currency":2,"amount":10}}` |
| gift | `{"stock":100,"price":{"currency":2,"amount":0},"reward_key":"gift1","reward":{"currency":1,"amount":2000}}` |

领奖幂等键：`act:{aid}:{uid}:{reward_key}`（签到 reward_key 带日期后缀）。

## 3. 验收

```powershell
docker compose up -d
# 启动 pandora-server 后
node server\scripts\activity_smoke.mjs
```

1. 三类活动可配置、可开关；热更后 list 立即反映  
2. 签到领奖幂等；任务经结算（或 simulate_settle）+N 并推 3001；礼包库存不超发  
3. game-web `/activity` 可领奖；大厅可进入  
4. admin-web 可 CRUD；审计有记录  
5. Activity 异常不阻断对局；M2–M4 冒烟仍可通过
