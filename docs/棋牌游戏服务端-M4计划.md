## 1. 范围

### 包含

- `MysqlClient` / `RedisClient`（无第三方库，WinSock + RESP / MySQL native）
- Admin 鉴权 RBAC：`super` / `ops` / `cs`；种子账号 `admin` / `admin123`
- SPEC §5.4 Admin REST（活动深度留给 M5，仅占位）
- 场次 / 充值档位热更；ban / kick / maintain；settle 写 `game_round`
- admin-web（Element Plus）全路由；`/activities` 占位

### 不做（M5+）

- 活动引擎与领取
- 真实支付宝验签
- 报表导出 Excel

---

## 2. 验收

```powershell
docker compose up -d
# 启动 pandora-server 后
node server\scripts\admin_smoke.mjs
cd admin-web; npm run dev   # http://127.0.0.1:5174  admin/admin123
```

1. `/health`：`mysql=true, redis=true`
2. 超管登录；补发幂等；场次 PUT 后大厅底分变化
3. 玩家 Token 访问 `/admin/*` 返回 1002
4. 写操作可见审计；M2/M3 冒烟仍可通过
