## 1. 范围

### 包含

- **HTTP + WSS 统一 IOCP**：`IocpPool` 固定 worker；accept 后 `PostQueuedCompletionStatus`，取消一连接一线程。HTTP 短请求走小线程池；WSS 长连接占用 worker（默认至少 256），后续可改为 overlapped `WSARecv` 进一步压线程数。
- CCU：`/health` 与 Dashboard 使用 `SessionHub::OnlineCount`
- Admin 报表 CSV：`/admin/v1/reports/{ledgers,rounds,claims}.csv`；admin-web 下载；审计
- `net.force_tls`：开启时拒绝明文业务（本地默认 false）
- 压测脚本 `server/scripts/ccu_load.mjs`

### 不做（后续）

- 完整 Schannel overlapped WSARecv/WSASend 与证书热加载
- 真实支付宝验签、冲榜

## 3. 验收

```powershell
node server\scripts\admin_smoke.mjs
node server\scripts\activity_smoke.mjs
node server\scripts\ccu_load.mjs --target 200
```

2. `/health` 含 `ccu`、`iocp_workers`  
3. Admin 可下载三类 CSV，审计有 `export_report`  
4. `force_tls=true` 时明文连接被关闭  
5. M2–M5 冒烟回归通过
